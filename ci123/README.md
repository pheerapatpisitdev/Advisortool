# CI 123 — หน้าข้อมูลประกันโรคร้ายแรง + เครื่องคำนวณเบี้ย (เวอร์ชันวานิลลา)

แปลงจาก React (`app/ci123`) เป็น **static** — รวมทุก component ไว้ในหน้าเดียว

## ไฟล์

- `index.html` — หน้าเว็บทั้งหมด (hero, ตารางผลประโยชน์, รายชื่อโรคแบบพับได้, เงื่อนไข/ตัวอย่างเคลม, เครื่องคำนวณเบี้ย)
- `data.js` — ข้อมูลเบี้ย (`window.CI123_PREMIUMS`, 7 ทุน × อายุ 0–70) + รายชื่อโรค (`window.CI123_DISEASES`) สร้างจาก `premiums.json` + `diseases.ts` ต้นฉบับ
- `cause-stats.png`, `Ex/EX1–3.png` — รูปประกอบ

ใช้ Tailwind ที่ compile ไว้ใน `styles.css`; ไม่มีการบันทึกข้อมูล/Supabase — เป็นหน้าข้อมูล + เครื่องคำนวณล้วน

## รัน / Deploy

```bash
python3 -m http.server 8080   # เปิด http://localhost:8080/ci123/
```

เวลา deploy ให้อัปโหลดทั้ง repo หรืออย่างน้อยโฟลเดอร์นี้พร้อม shared `assets/`

## หมายเหตุการแปลง

- คำนวณเบี้ย: รายปี = ค่าในตาราง, ราย 6 เดือน = `round(ปี × 0.52)`, รายเดือน = `round(ปี × 0.09)` (สูตรเดิม) — ตรวจแล้วตรงกับต้นฉบับทุกค่า
- รายชื่อโรคพับได้ใช้ทริค Tailwind `grid-rows-[0fr]` ↔ `grid-rows-[1fr]` (เหมือนต้นฉบับ) สลับด้วย JS
- ปุ่ม "ดูเงื่อนไข" / "ตัวอย่างการเคลม" toggle ทีละอัน, ไอคอน lucide → inline SVG
- แชร์ LINE = `https://line.me/R/msg/text/?...` (ไม่ต้องใช้ token)
