# Advisortool — HTML + CSS + JS วานิลลา

เว็บ static พร้อมไฟล์ที่ bundle สำหรับใช้งานแล้ว ไม่ต้อง build ตอนเปิดใช้งานและวางบน static host ได้ทันที (Easy Protect 6 เก็บ TSX ต้นฉบับไว้คู่กับ `app.js` ที่ compile แล้ว)

## หน้า Hub

`index.html` (รากของ repo) = หน้ารวมเครื่องมือทั้ง 14 ตัว กดการ์ดเพื่อเข้าใช้งานแต่ละตัว

> Header แถบบน (โลโก้ + เมนู "เครื่องมือ") ของทุกหน้าใช้ไฟล์กลางร่วมกันที่ `assets/global-header.css` + `assets/global-header.js` — แก้เมนู/สไตล์ที่เดียว มีผลทุกเครื่องมือ

## รัน

เสิร์ฟ root ของ repo ด้วย static server แล้วเปิดหน้า Hub:

```bash
npm run dev
# เปิด http://localhost:8080  → กดการ์ดเข้าแต่ละเครื่องมือได้เลย
```

> ควรเปิดผ่าน HTTP (ไม่ใช่ `file://`) เพื่อให้ path ของ asset, การสร้าง PDF/ภาพ และ PIN gate ทำงานสม่ำเสมอ
