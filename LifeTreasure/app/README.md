# โปรแกรมคำนวณเบี้ยประกัน ไลฟ์เทรเชอร์ (A2026-1)

สร้างจากสูตรในไฟล์ `ไลฟ์เทรเชอร์_A2026-1.xlsx` (ชีต Cal / กรอกข้อมูล / ตารางแสดงผลประโยชน์
และตารางอัตราเบี้ยทั้งหมด) — ผลลัพธ์คือเว็บแอปไฟล์เดียว:

**`../ไลฟ์เทรเชอร์-คำนวณเบี้ย.html`** — ดับเบิลคลิกเปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร
ใช้งานออฟไลน์ได้ (ฟอนต์สวยขึ้นเล็กน้อยเมื่อออนไลน์) ส่งไฟล์ต่อให้ตัวแทนคนอื่นได้ทันที

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `extract_rates.py` | ดึงตารางอัตราเบี้ยทั้งหมดจาก Excel -> `rates.json` |
| `rates.json` | อัตราเบี้ยหลัก, PB, WP, AP/ECARE, MEB, DCI/PLS/CPR/HIC, MEX, iHealthy Ultra, โรคร้ายโซชิลด์, CI 123, ตารางมูลค่าเวนคืน (TABCV ชาย/หญิง) |
| `engine.js` | เอนจินคำนวณ จำลองสูตร Excel ตรงเป๊ะ (รวมการปัดเศษ ROUNDDOWN/TRUNC) |
| `template.html` | หน้าจอ UI + สไตล์ + สคริปต์ผูกฟอร์ม + ใบเสนอสำหรับพิมพ์ |
| `build.py` | ประกอบ template + rates + engine -> ไฟล์เดียว |
| `test_baseline.mjs` | เทสต์เทียบค่า cached ในไฟล์ Excel (33 จุด) |
| `golden_test.py` | เทสต์ 12 สถานการณ์: ตั้งค่า input ในไฟล์ Excel จริง ให้ LibreOffice คำนวณใหม่ แล้วเทียบทุกเซลล์ (เบี้ยทุกตัว + ข้อความ error + ตารางผลประโยชน์ทุกแถว) |
| `serve.mjs` | เว็บเซิร์ฟเวอร์ทดสอบ (ไม่จำเป็นต่อการใช้งานจริง) |

## วิธีแก้ไข / อัปเดตเวอร์ชั่นใหม่

1. วางไฟล์ Excel เวอร์ชั่นใหม่แทนที่เดิม (หรือแก้พาธใน `extract_rates.py`)
2. `python3 extract_rates.py` — ดึงอัตราใหม่
3. `python3 build.py` — ประกอบไฟล์แอปใหม่
4. ตรวจสอบ: `node test_baseline.mjs && python3 golden_test.py`
   (golden test ต้องมี LibreOffice: `brew install --cask libreoffice`)

## หมายเหตุความถูกต้อง

- การปัดเศษทุกขั้นทำแบบ Excel: ทุน/1000 ตัด 3 ตำแหน่ง, เบี้ยตัดทิ้ง 2 ตำแหน่ง,
  HIC ใช้ ROUND ตามสูตรต้นทาง, PB/WP ใช้ TRUNC ของเบี้ยฐาน/100
- อัตรา CI 123 ใช้ชีต `Rate CI 123` ในไฟล์ (สูตรต้นทางอ้างไฟล์ SharePoint ภายนอก
  ซึ่งมีข้อมูลชุดเดียวกัน — ยืนยันจากค่า cached แล้ว)
- แผน iHealthy Ultra แบบ Deductible มีอัตราเฉพาะพื้นที่ประเทศไทย (ในตารางต้นทาง
  คอลัมน์เอเชีย/ทั่วโลกของ Deductible ไม่มีอัตรา) แอปจึงล็อกพื้นที่เป็นประเทศไทยเมื่อเลือก Deductible
- โปรแกรมข้อเสนอเวอร์ชั่นนี้รองรับงวด รายปี / ราย 6 เดือน / รายเดือน ตามไฟล์ต้นทาง
  (dropdown ต้นทางตัดราย 3 เดือนออกสำหรับเวอร์ชั่น A)
